- **feat(home):** the Home page shows usage at a glance — token, cost, error and fallback cards, usage by combo, an activity heatmap and a range selector — next to a Provider Quota card for every active connection. The token and cost cards show the change against the previous period of the same length (not for `All`, and hidden when there is no baseline). A loading skeleton and a retry button replace the blank and error states. The quota card fills the height of the usage block and scrolls inside it one whole page of providers at a time, so none is ever cut in half; its bars are exposed as progress bars. New `GET /api/usage/by-combo` endpoint. Three new switches in Settings → Appearance (`showUsageStatsOnHome`, `showActivityHeatmapOnHome`, `showProviderQuotaOnHome`) let you hide each block; all default to on.
